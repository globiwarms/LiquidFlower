# LiquidFlower

Меню из лепестков у курсора для Windows 10/11. Нажмите колёсико мыши — вокруг курсора появляются лепестки с быстрыми действиями. Стиль Apple Liquid Glass.

## Использование

1. Скачайте `LiquidFlower.exe` из [последнего релиза](../../releases/latest) и запустите — программа появится в трее.
2. Откройте меню лепестков — колёсико мыши (по умолчанию).
3. Настройки — шестерёнка в центре меню или левый клик по иконке в трее.
4. Клик по лепестку выполняет действие и закрывает меню. ЛКМ/ПКМ по пустому месту — просто закрывает.
5. Выход — правый клик по иконке в трее → «Выход».

## Возможности

- До 8 лепестков: иконка, название, цвет и действие каждого настраиваются.
- Действия: приложение (.exe/.lnk), ссылка, звук, микрофон, тише/громче, пауза, треки, спящий режим, завершение работы, свернуть все окна.
- Анимации (цветение / каскад / волна), прозрачность, Liquid Glass, свечение, размер.
- Своё сочетание клавиш для вызова, автозапуск, звуки меню.

## Требования

- Windows 10/11 x64 с Microsoft Edge WebView2 (предустановлен в Windows 11 и в большинстве Windows 10).

## Примечания

- В играх используйте режим «окно без рамки» (borderless) — оверлей поверх него работает.
- Настройки хранятся в `%APPDATA%\LiquidFlower`.
